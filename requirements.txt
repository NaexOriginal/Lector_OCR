#    CPU:
#        pip install paddlepaddle==3.2.0 \
#            -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
#
#    GPU (17 veces mas rapido: 3,83 s -> 0,22 s por imagen, medido):
#        pip install paddlepaddle-gpu==3.3.1 \
#            -i https://www.paddlepaddle.org.cn/packages/stable/cu129/
#
#    La rueda cu129 hace falta para las GPU Blackwell (sm_120), que necesitan
#    CUDA 12.8 o superior. Con una rueda cu118 o cu126 el import funciona y la
#    GPU no se usa -- y eso es peor que un error, porque no se nota.
